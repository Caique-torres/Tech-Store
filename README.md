#  TechStore

Uma aplicação web de e-commerce desenvolvida com HTML, CSS e JavaScript, criada para apresentar produtos de tecnologia e simular uma experiência de loja virtual.

##  Demonstração

 [Clique aqui para acessar o TechStore](https://caique-torres.github.io/Tech-Store/)

##  Funcionalidades

- Apresentação da loja  
- Catálogo de produtos  
- Notebooks  
-  Smartphones  
- Acessórios  
- Busca de produtos  
- Filtro por categorias  
- Carrinho de compras  
- Adicionar produtos ao carrinho  
- Alterar quantidade de produtos  
- Remover produtos do carrinho  
- Cálculo automático do total  
- Armazenamento do carrinho com LocalStorage  
- Seção de ofertas  
- Formulário de contato  
- Interface responsiva  
- Menu lateral de navegação  
- Simulação de finalização da compra  

##  Tecnologias utilizadas

- HTML5  
- CSS3  
- JavaScript  

##  Objetivo

Este projeto foi desenvolvido para colocar em prática conhecimentos de HTML, CSS e JavaScript, trabalhando principalmente com criação de interfaces web, organização de produtos, responsividade, navegação entre seções, filtros, busca, formulários, manipulação do DOM e armazenamento de dados no navegador.

O projeto também foi desenvolvido para simular uma loja virtual de tecnologia, permitindo trabalhar com catálogo de produtos, categorias, pesquisa, carrinho de compras, controle de quantidade e cálculo do valor total da compra.
